# SimpleCADAPI 2.1.1 更新说明

[English](2.1.1.md)

> **发布说明：** 用于生产前，请验证生成的定义、装配约束和制造几何。

2.1.1 是一个工具链补丁版本：**SDK 公共 API 无变化**。新增 CadQuery→FTC
翻译工具集（`tools/research/cadqueryftc`），以及一个把平面几何快照恢复成
完全铆定草图约束组的约束恢复引擎。

## CadQuery → FTC 翻译工具集

与 `tools/research/histjson` 对齐的四阶段研究工具（trace / translate /
validate / profile）。责任墙一致：**翻译器只翻译**，对错与精度问题全部
外置给验证器。

- **运行时 tracer**（`cadquery_trace.py`）：在真实 cadquery 2.8 解释器下
  执行程序（独立 Python 3.11 venv；仓库官方 pin 不动），monkey-patch
  `cq.Workplane` 记录 resolve 后的平面标架、序列化实参、选择器字符串、
  以及**实际选中面/边的几何指纹**——不记 CadQuery 拓扑索引，只记几何。
  每个程序顺带捕获真值体积与包围盒；trace JSON 是两个环境之间唯一的
  握手物。
- **FTC 翻译器**（`cadquery_to_ftc.py`）：单遍重放器发射现行约定的 FTC
  源码——闭集角色块头、sketch API 平面剖面（诚实标注 `profile=geometry`
  转录几何：精确局部坐标、点池去重、外心三点弧）、bodies 数据流的列表形
  布尔、从指纹合成的 QL 谓词选集（`.take(n).exactly(n)` 基数）、由包围盒
  推导的穿透刀具长度，以及**全 keyword 实参**发射（语料自带参数语义）。
  生成源码零自检。
- **外置验证器**（`cadquery_validate.py`）：执行生成源码，体积/包围盒对
  trace 真值对账，分级 accepted / partial / rejected。

## 快照约束恢复

`--constraints on` 额外从逐块几何快照（`*.sketches.json`，来源无关的
公共接口——任何能产出平面环/开链的前端都能接）恢复推断约束组：

- 候选全部是被快照**实际满足**的关系；
- 准入判据是生产 SolveSpace solver 的 DOF 下降，引入冗余的候选拒收——
  DOF 计数器会被秩亏系统欺骗；
- **盆地检验**（扰动重建必须收敛回快照坐标）是保真度的最终裁决；
- 测量值原样发射；id 一律 `inf` 前缀，声明推断出处、绝不冒充数据集原生
  约束。

草图捕获只有一个咽喉点（`SketchScript.render` 触发 sink），所有构造位
——普通剖面、loft/taper 截面、沉孔锥、sweep 路径、pattern 种子——构造
即捕获。

## 验证

- cadquery 2.8.0 真实捕获的 trace 作为 fixtures 入库；26 个测试在**不装
  cadquery** 的 CI 环境钉住格式契约、体积对账、keyword 语料与捕获完整性。
- 对账数字：washer 1.6e-16、rarray 0.0、revolve 1.8e-16、hexnut 2.2e-12
  相对体积误差（含 `edges(">Y").chamfer` 的 QL 选边）；双锥台 16 销孔
  pulley 的 5/5 草图约束铆定。

## 限制

- taper 拉伸仅圆剖面精确（锥台=双截面 loft）；开口线不能 sweep；pattern
  草图支持 rect/circle/闭合 wire。
- 60+ 点自由轮廓在恢复预算下诚实降级为 `timeout`；几何翻译不受影响。
- 源程序手写展开的阵列按原样翻译（特征级阵列折叠是已知的后续能力）。
