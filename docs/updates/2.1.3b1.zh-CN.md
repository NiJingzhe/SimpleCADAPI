# 2.1.3b1 更新说明

> **发布说明：** 预发布（beta）。用于生产前，请验证生成的定义、装配约束和制造几何。

## 插件生态：`sca` 插件管理 CLI

新的 `sca` 命令行安装第三方插件包——skill + 工具仓库，为建模以外的环节
（仿真、分析、下游工具链）提供能力，消费 `.scadpkg` 产品包：

```bash
sca addon init                     # 每台机器一次：home + registry + config
sca addon add owner/repo@v1.2.0    # 从 GitHub 安装（tag/commit pin）
sca addon add ./my-addon           # 本地目录试装（发布前验证）
sca addon update [name]            # 重取一个或全部插件
sca addon remove name
sca addon list                     # registry 内容 + 磁盘漂移
```

- **描述文件 `sca-addon.toml`**（仓库根）严格校验——未知表/键一律拒绝、
  每次失败点名字段：插件身份、`[compat] sca` 版本区间（区间不 pin：
  逗号分隔的 `== != >= <= > <` 子句，预发布后缀排在对应发布之前、缺尾
  分量按零补齐、矛盾子句直接拒绝）、封闭六值平台枚举（`macos-arm64`、
  `macos-x86_64`、`linux-x86_64`、`linux-aarch64`、`windows-x86_64`、
  `windows-arm64`）、`check_cmd` 运行时探针（退出码 0 即可用、shell 钉死
  `sh -c` / `cmd /c`、约两秒、禁网络/license/GUI；探针失败大声警告但绝不
  拦截安装）。
- **硬门与警告**：描述文件无效、`[compat] sca` 区间不配、平台不支持、
  重名、外来 skill 目录——安装中止并点名确切原因；探针失败、update 版本
  回退——大声警告。
- **安装布局**：addon home + `~/.sca/config.toml` 解析链（标志 >
  `SCA_ADDON_HOME`/`SCA_SKILLS_DIR` 环境变量 > config > 默认值
  `~/.sca/addons` 与 `~/.agents/skills`；CLI 永不写 shell profile）、
  记录装了什么装在哪的 `registry.json`、skill 拷贝（非 symlink）为
  `sca-<name>`、GitHub 源默认走 tarball（不需要 git 二进制；私有仓库
  `--method clone`），解包带符号链接/路径逃逸守卫。

## 插件的两种合法集成模式

评审后的契约：默认推荐语言无关的进程边界（插件消费 `.scadpkg` 文件与
进程级工具；依赖冲突结构上不可能）；插件在自己环境里进程内使用 SDK 明确
允许——builtin 导出器与包读取器（`read_product_package`、
`load_product_package`）正是为这类下游消费者准备的，`[compat] sca` 管辖
该依赖可解析到的 SDK 版本。两种模式下插件都不装进跑建模的 SDK 环境。

## `.scadpkg` 消费者格式规范

`docs/skill/references/scadpkg-format.md` 面向消费者记录持久包格式：成员
布局（`package.json` manifest、definitions、装配发生图、场景投影、内容寻址
`blobs/`）、sha256 解析铁律（引用的 `path` 是逻辑名——一切经 manifest 按
`sha256` 解析）、`interface.*` 标签通道（`name_index` 把公开名字映射到同
kind 实体；缺失的必需名字=点名大声失败，绝不按几何猜）、两路最小解析器
——进程内 SDK 与任意语言的纯 ZIP+JSON。两段示例代码均对真实包执行验证。
插件创作指南（`references/domains/addon-development.md`，已接入 skill
路由）把导出器作者指向它；规范 JSON Schema 随 wheel 分发于
`simplecadapi/contracts/`。

## 内务

- 移除死合同 `product-package-2.schema.json`：加载器只按
  `product-package-3.schema.json` 校验，v2 文件无任何读取方。

## 兼容性说明

- 新 `sca` 命令行入口是纯增量；本发布未改动任何 SDK API。
- 移除 v2 schema 文件只影响 wheel 的静态载荷；当前 SDK 产出的包
  （schema 3.0）不受影响。
