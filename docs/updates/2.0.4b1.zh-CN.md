# SimpleCADAPI 2.0.4b1 更新说明

[English](2.0.4b1.md)

> **Beta 版本提示：** 以下改动将在 2.0.4 正式版之前继续验证。用于生产前，
> 请检查生成的 CAD 文档。

SimpleCADAPI 2.0.4b1 改进了 FreeCAD 文档语义、装配稳定性、布尔并集行为和
标准轴承复用。

## 1. 具有建模语义的 FreeCAD 文档

FreeCAD translator 现在会把源码赋值目标和建模意图映射为人类可读的对象 Label，
同时保留规范化 node id，继续用于稳定回放和追溯。转换后的可见几何按照产品建模逻辑
组织，不再向用户展示扁平的 graph operation 列表。

装配模型的 Tree View 只展示一个最终产品根；非产品模型则展示独立几何根。
Construction 对象、`App::Link` 源定义和预览 compound 仍保留在文档中支持重算，
但不会作为重复的顶层模型显示。

## 2. FreeCAD 装配稳定性

通过柔性 `Assembly::AssemblyLink` occurrence 复制的约束，现在会恢复完整的原生
Joint ViewProvider。激活转换后的装配体时，求解器可见的关节可以正常重绘，不再触发
此前的 joint placement 重绘故障。

Occurrence 生成和最终文档保存会保留预期的 Part、Component、Connector、Joint、
Material 和 Visibility 关系，并写入最终 `.FCStd` 文档。

## 3. 可靠的 Boolean Union 语义

`union_rsolid(...)` 现在默认使用 OCC 普通 Fuse 路径。`glue=True` 是可选优化：
当 GlueShift 返回多个 Solid 时，SimpleCAD 会自动使用 GlueOff 重试，并采用重试操作
自身的拓扑历史。

共享有限面积的面或存在正体积交叠时，可以直接生成一个流形 Solid，调用方无需人为
制造交叠。只有边、顶点、切点或切线接触时，仍会明确失败，因为这些关系不能组成一个
流形 Solid。显式 fuzzy tolerance 必须是有限且非负的数值；只有明确接受几何近似时，
才应使用它连接真实的小间隙。

## 4. 标准融合轴承与 BLDC 迁移

`scad.std.bearing.make_ball_bearing_rassembly(...)` 现在可以把装饰性滚珠融合进外圈，
同时保留内外圈 Revolute Joint。融合模式只向求解器暴露 `outer_ring` 和 `inner_ring`，
会在轴承 metadata 中记录这一简化，并支持材料赋值。内部 Part id 现在以 `assembly_id`
作为命名空间，因此同一 `GraphSession` 可以创建多种轴承尺寸而不会发生 id 冲突。

集成 BLDC 执行器中的电机轴承、中间级轴承、行星轴承和输出轴承，现在全部使用标准库
轴承工厂。生成的 FreeCAD 模型包含 11 个轴承实例；每个实例由一个融合滚珠的外圈
Solid 和一个内圈 Solid 组成，不会向 FreeCAD Simulation 暴露未约束的滚珠刚体。

## 5. 验证

本版本新增了以下回归覆盖：共享面并集、复杂曲面在 glue 优化下的并集、非流形边接触
和相切接触、非法 fuzzy tolerance、融合标准轴承、多轴承定义、BLDC 轴承契约，以及
转换后 FreeCAD 装配体的激活行为。
