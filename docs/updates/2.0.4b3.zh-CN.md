# SimpleCADAPI 2.0.4b3 更新说明

[English](2.0.4b3.md)

> **Beta 版本提示：** 用于生产前，请验证生成的定义、装配约束和制造几何。

SimpleCADAPI 2.0.4b3 新增可复现的产品构建边界，以及覆盖整零件和增量装配求解的
持久化、崩溃安全缓存。

## 1. 持久零件与装配定义

`@scad.part` 构建且只构建一个物理单实体零件，返回 `PartBuildResult`：运行时
`Part`、`PartDefinition`、图和 session 状态、model/session JSON、接口差异以及
单次构建的 `CacheReport`。内容派生 key 覆盖规范化参数、builder 源码、声明的文件
输入、revision、容差 profile 和 generator/ABI profile。

`@scad.assemble` 要求显式传入外部 `PartDefinition` 或嵌套
`AssemblyDefinition`。重复实例共享不可变定义；封闭校验会拒绝缺失、未使用、循环、
冲突或不兼容引用。定义可脱离进程内运行时对象独立往返。

## 2. 增量装配求解

装配状态记录组件依赖和公共 connector 接口。几何、connector、connector binding、
材料或嵌套装配公共 connector 声明的变化，只沿受影响的依赖路径传播。未变化组件的位置
可以从缓存恢复，但每个恢复位置仍必须先通过约束残差验证。

## 3. PRT 复用

在 `read_only` 和 `read_write` mode 下，同一 `@scad.part` 装饰器、同一 build key
直接复用一个运行时 PRT，不读取持久 cache；并发同 key 调用也只执行一次 builder。
`off` 和 `refresh` 仍按显式语义强制重建。

持久整零件 bundle 仍是跨运行边界。重新装饰的 builder 或后续进程会从校验通过的
bundle 恢复未变化 PRT，并创建全新的运行时图 provenance。损坏 record 或 object
会退化为 miss，并在重新计算前隔离。

## 4. 崩溃安全内容存储与策略

共享 CAS 使用规范封闭 record、SHA-256 object、原子写入、逐 key 锁、陈旧锁恢复和
对象去重。

一份 `CachePolicy` 同时控制 part 和 assembly cache。优先级为显式 API 参数、环境
变量、`[tool.simplecadapi.cache]`、默认值。支持 `off`、`read_only`、`read_write`
和 `refresh` 四种模式。

## 5. Cache 诊断 CLI

新增 `simplecad-cache` 命令，输出稳定 JSON：

```text
simplecad-cache status [--namespace NAME]
simplecad-cache verify [--namespace NAME] [--repair]
simplecad-cache prune [--apply]
simplecad-cache clear [--namespace NAME] --yes
```

检查和默认 prune 均只读。修改状态必须显式传入 `--repair`、`--apply` 或 `--yes`。
`verify` 总会校验 record 身份、object 是否存在、字节长度和 SHA-256。按 namespace
清理时，仍被其他 namespace 引用的 object 会保留。

## 6. 原生渲染崩溃隔离

在 macOS 上，VTK 9.5 的 Cocoa 离屏后端在反复或并发使用 render window 后可能通过
`SIGSEGV` 直接终止解释器。Inspection 与 SDK screenshot 现在由调用进程完成离散化，
再交给受跨进程锁保护的一次性 VTK worker 渲染。完成标记用于区分完整图片与原生崩溃
产生的半成品；未完成的 worker 会重试，而图片写完后的 teardown 崩溃不会再终止建模
进程或测试进程。

## 7. 验证


回归测试覆盖 artifact schema 封闭性、确定性 ID/hash、并发原子写入去重、损坏隔离、
全部 cache mode、进程内同 key PRT 复用、并发 PRT 构建去重、跨装饰器持久 part 恢复、
接口失效、assembly definition DAG、增量依赖传播、残差验证和嵌套 connector 变化。

代表性外部引用齿轮系 smoke 会构建两个缓存零件，求解重复与嵌套装配实例，导出独立
assembly definition 归档，重新加载并 materialize，然后验证嵌套约束残差。
