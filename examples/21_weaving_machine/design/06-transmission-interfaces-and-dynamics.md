## 1. 架构原则

采用“分布式伺服 + 必要支路机械正同步”：

- 导向块与偏斜供纱链必须机械锁相。
- A40/A41 固定框架内的四排导向块必须按 03 的方向表镜像同步。
- 左右挂钩必须机械同步。
- 牵引左右丝杠必须机械同步。
- 拉剑、针、接合杆和筘可以独立伺服驱动，由虚拟主轴相位协调。

不建议在缺少原论文凸轮尺寸和载荷的情况下复制一根机械总轴驱动整机，也不允许把关键一一对应关系完全交给两个无机械联系的电机。

## 2. 驱动轴表

| 轴 | 功能 | 传动 | 初始功率级别 |
|---|---|---|---:|
| M1 | 上下导向块与上下偏斜供纱链索引 | 行星减速器、扭矩离合器、共用凸轮轴 | 400 至 750 W |
| M2 | 上下粘合针反向升降 | 双面同步带或共轭凸轮 | 400 W |
| M3 | 三根拉剑横移 | HTD 同步带、双导轨 | 750 W |
| M4 | 接合杆 1 升降 | 短丝杠或曲柄 | 200 至 400 W |
| M5 | 接合杆 2 升降 | 滚珠丝杠 | 200 至 400 W |
| M6 | 接合杆 2 前后 | 滚珠丝杠 | 400 W |
| M7 | 开放式筘升降 | 滚珠丝杠 | 400 W |
| M8 | 开放式筘水平打纬 | 滚珠丝杠和力传感器 | 750 W |
| M9 | 左右挂钩插入 | 横向同步轴、两侧凸轮滑块 | 200 至 400 W |
| M10 | 直线牵引 | 抱闸伺服、双丝杠机械同步 | 400 至 750 W |

功率仅用于 CAD 包络和采购级别预估。正式选型必须根据实测摩擦、移动质量、加速度、纱线张力和峰值打纬力计算。

## 3. 必须机械同步的支路

### 3.1 偏斜索引

```text
M1
→ 20:1 行星减速器
→ 扭矩限制离合器
→ 主索引轴
├→ 上框架共轭凸轮
├→ 下框架镜像共轭凸轮
├→ 上供纱链一步索引器
└→ 反向齿轮 → 下供纱链一步索引器
```

一次局部凸轮循环只允许完成一个导向块节距和一个筒子工位。轴端使用胀套或键连接，并保留相位刻线和机械零槽。

### 3.2 左右挂钩

```text
M9
→ 减速器
→ 横向同步轴
→ 左凸轮滑块
→ 右反向凸轮滑块
```

左右挂钩同时插入，最终位置相对 `Y=0` 镜像。

### 3.3 双丝杠牵引

```text
M10
→ 抱闸减速器
→ 左丝杠
→ 同步横轴
→ 两组锥齿轮
→ 右丝杠
```

机械横轴保证掉电或单传感器故障时左右夹具不失去相对位置。

## 4. 机械接口分类

| 接口 | 内容 | 要求 |
|---|---|---|
| 定位接口 | 基准面、圆柱销、菱形销、止口 | 拆装后可重复找正，避免过定位 |
| 动力接口 | 轴端、胀套、同步带轮、链轮、联轴器 | 标注转向、速比、扭矩、相位零点 |
| 工艺接口 | 导眼、针孔、拉剑通道、筘缝、挂钩口 | 标注纱线中心、包络和最小圆角 |
| 状态接口 | 原点片、硬限位、锁爪、扭矩限制器 | 机械状态可检测，不用时间推测 |
| 维护接口 | 快拆挡圈、耐磨条、筘盒、针夹 | 易损件不拆主框架即可更换 |

固定件采用“一圆销一菱形销 + 夹紧螺栓”。丝杠驱动端固定支承、远端浮动支承。长推杆用两个有足够跨距的轴套支承，禁止单轴套长悬臂。

## 5. 载荷路径

### 5.1 导向块索引

```text
M1
→ 减速器
→ 扭矩离合器
→ 索引轴
→ 凸轮
→ 滚轮从动件
→ 推杆/转层梭
→ 导向块链
→ 耐磨轨
→ 框板
→ 织造门架
→ 主底架
```

中央经纱导向板只承担经纱导向反力，不承担导向块推力。

### 5.2 打纬

```text
M8
→ 减速器和丝杠
→ 筘水平滑台
→ 力传感器/连接块
→ 筘座
→ 筘片
→ 填充纱和成型线
→ 挂钩与牵引夹具
→ 牵引架
→ 主底架
```

筘垂直轴只负责升降，不承担主要水平打纬反力。

### 5.3 牵引

```text
M10
→ 双丝杠
→ 螺母座和夹具
→ 已成型织物
→ 全部纱线张力
→ 张力器和供纱架
→ 主底架
```

供纱、织造和牵引支架必须安装在同一底架形成闭合力流。

## 6. 初步力和扭矩模型

### 6.1 导向索引扭矩

```text
T_guide,out = [(F_slide + F_yarn + F_transfer) × r_cam + J_guide,eq α_G] / η_guide
```

- `F_slide`：导向块链最大滑动阻力。
- `F_yarn`：偏斜纱横向合力。
- `F_transfer`：左右转层梭阻力。
- `r_cam`：凸轮等效作用半径。
- `J_guide,eq`：四排导向块、推杆、从动件和转层梭折算到 M1 公共输出轴的等效惯量。
- `α_G`：M1 公共输出轴在索引段的角加速度。
- `η_guide`：公共输出轴至导向机构的支路效率，不包含 M1 减速器。

单根纱线改变方向作用于导向块的横向分力：

```text
F_yarn,i ≈ 2T_i sin(Δα_i/2)
```

不可只按空载塑料块摩擦选电机和凸轮。

### 6.2 偏斜供纱链惯量

```text
J_chain,eq = Σ(m_i r_i²) + J_sprockets + J_transmission
T_chain,j,out = (J_chain,j,eq α_j + T_friction,j + T_yarn,j + T_index,j) / η_chain,j
T_M1,motor >= K_s × (T_guide,out + T_chain,upper,out + T_chain,lower,out) / (i × η_drive)
```

所有相加扭矩先计入各自支路效率 `η_guide` 或 `η_chain,j`，再折算到 M1 减速器同一输出轴。`i=20` 为当前减速比，`η_drive` 只包含 M1 减速器和输入联接效率，不重复包含输出支路损失；`K_s` 为污染、冲击和不均匀张力安全系数，建议不小于 2。按满筒和空筒两种极限状态验算；链轮转弯处检查筒子摆动和邻件动态包络。

### 6.3 拉剑

```text
F_rapier = m_move a + F_belt + F_guide + F_pickup
```

载板使用宽跨距双导轨，三根剑杆根部形成箱形连接。拉剑一阶固有频率要与往复激励频率充分分离。

### 6.4 粘合针

```text
P_cr = π²EI / (K L)²
```

`E`、`I` 和 `L` 分别为针材弹性模量、截面二次矩和无支承长度；意外碰纱按固定-自由悬臂取 `K=2`。轴向压力应显著低于屈曲载荷。针根部过渡圆角和夹持长度需要进入疲劳校核。

### 6.5 筘和门架

打纬是主要冲击源。初始刚度目标：

```text
δ_reed_total <= 0.10 mm
```

达不到时优先增加导轨跨距、筘座截面和门架刚度，或降低接触加速度，不用控制误差补偿结构挠度。

### 6.6 夹具

防滑条件：

```text
μ N_clamp >= F_takeup × K_s
```

同时夹垫压力不得压碎纱束或造成层间错移。摩擦系数和允许压力必须用目标织物实测。

## 7. 反力平衡

固定的 A40/A41 框架内，四排导向块和两侧转层件按镜像方向运动，可抵消部分一阶侧向惯性反力：

```text
F_reaction,Y = Σ(m_j a_Y,j)
```

求和包含四排导向块、推杆、从动件和转层梭的全部 `Y` 向等效活动质量。按方向分成 `+Y` 和 `-Y` 两组后，当成对活动质量近似相等、加速度方向相反时，总侧向反力减小。为此：

1. 四排推杆、转层梭和导向块活动质量尽量镜像。
2. 上下供纱链满筒质量分布相近。
3. 反向齿轮支路保持低背隙。
4. 同步运动使用相同 S 曲线。

## 8. 运动曲线

- 所有伺服采用限加加速度 S 曲线。
- 导向块端块进入转层梭时低速。
- 拉剑在拾纱和释放区设置速度平台。
- 筘接触填充纱前降低速度，并以力传感器限幅。
- 丝杠轴不得在临界转速附近运行。
- 扭矩限制离合器只保护卡滞，不作为正常定位元件。

## 9. 动态验算清单

1. 满筒/空筒偏斜供纱链惯量。
2. 洁净、粉尘污染、最大纱线张力三种导向索引阻力。
3. 上下反向机构的机架反力平衡。
4. 拉剑挠度和一阶固有频率。
5. 粘合针屈曲、弯曲和疲劳。
6. 筘峰值力、丝杠寿命和门架挠度。
7. 牵引夹具梁挠度和夹持压力分布。
8. 双丝杠临界转速、同步轴扭转角和寿命。
9. 完整周期激励频率与机架固有频率分离。
10. 急停制动距离和停止后的无碰撞姿态。
