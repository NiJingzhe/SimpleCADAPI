## 1. 经纱供料

PDF 明示每根经纱使用独立筒子和张力补偿器，弹簧刚度决定张力，张力超过锁止力矩后释放纱线。[PDF p1.t26-p1.t31] [PDF p2.t3-p2.t5] [PDF 图3.21: p3; p3.t19]

### 1.1 单个筒子模块

| 编号 | 零件 | 结构 |
|---|---|---|
| W-01 | 筒子芯轴 | 不锈钢轴，双轴承支承 |
| W-02 | 快拆挡圈 | 筒子轴向定位 |
| W-03 | 摩擦制动盘 | 摩擦片、压簧和调节螺母 |
| W-04 | 张力摆臂 | 铝合金曲柄，端部陶瓷眼 |
| W-05 | 摆臂枢轴 | 滚针轴承或含油轴套 |
| W-06 | 张力弹簧 | 可调拉簧或恒力弹簧 |
| W-07 | 锁止滑块 | 抑制筒子惯性放纱 |
| W-08 | 张力传感器 | 断纱和越限检测 |

纱线路径：

```text
筒子
→ 张力摆臂陶瓷眼
→ 固定导向眼
→ 对应层导向板
→ 中央固定经纱导向孔
→ 织造区
→ 成型线
```

经纱穿过固定、光滑的圆孔，不使用传统综框开口。[PDF p2.t10-p2.t14]

## 2. 偏斜纱移动供纱链

偏斜筒子安装在循环链条上，筒子布置在链条两侧以平衡质量，每次链条索引对应一次偏斜纱输送。[PDF p2.t15-p2.t21] [PDF 图3.22: p4; p4.t13]

### 2.1 每套链条总成

| 编号 | 零件 | 结构 |
|---|---|---|
| B-01 | 双承载链 | 两条平行精密滚子链，避免单链扭转 |
| B-02 | 主链轮 | 不少于 17 齿，胀套或键连接 |
| B-03 | 从链轮 | 可调滑座支承 |
| B-04 | 筒子承载板 | 跨两链连接，带筒子轴和配重孔 |
| B-05 | 移动张力器 | 每个筒子独立摆臂和制动器 |
| B-06 | 链条导轨 | UHMW-PE 长直边支承 |
| B-07 | 张紧滑座 | 螺杆调节加碟簧补偿 |
| B-08 | 陶瓷导向辊 | 每根偏斜纱独立导向 |
| B-09 | 工位编码板 | 与导向块编号一一对应 |
| B-10 | 原点片 | 机械零位检测 |

上链服务上导向框架，下链服务下导向框架。两链每完整周期各移动一个工位，方向相反。相邻筒子交替安装在链条内外侧，并按满筒质量配平。

## 3. 导向块几何

每根偏斜纱穿过一个独立导向块，导向块围绕中央经纱导向板沿封闭矩形路径循环。[PDF p3.t20-p3.t31]

| 部位 | 结构要求 |
|---|---|
| 块体 | PEEK、POM-H 或耐磨含油塑料 |
| 母形 | 圆角八边柱或带导向肩的圆角矩形柱 |
| 中心孔 | 压入氧化铝陶瓷眼 |
| 左右面 | 浅凸/浅凹接触面，传递推力并允许微浮动 |
| 前后面 | 导向肩嵌入框板槽，限制绕纱线轴旋转 |
| 上下面 | 与可更换耐磨条形成滑动副 |
| 标识 | 与偏斜供纱链相同的永久编号 |

初始间隙：宽度方向每侧 `0.08...0.15 mm`，厚度方向总间隙 `0.10...0.20 mm`。陶瓷眼内径为最大纱束直径的 `1.5...2 倍`。

## 5. 三阶段换位

### A. 端块捕获

1. 定位锁爪抬起。
2. A40 的 G-06U 捕获上排右端块，G-05U 捕获下排左端块。
3. A41 的 G-05L 捕获上排左端块，G-06L 捕获下排右端块。
4. 四排随动杆保持轻预载。

### B. 反向横移和转层

以下方向描述 A40 上框架。A41 下框架采用反相循环：

1. A40 上排向 `+Y` 移动一个节距 `p`。
2. A40 下排向 `-Y` 移动一个节距 `p`。
3. A40 右梭下降、左梭提升；A41 左梭下降、右梭提升。
4. 每个框架的两个端块进入另一排空出的接收位。

### C. 入位、锁定和复位

1. 转层梭把端块完全送入目标排。
2. 随动杆校正整排压紧长度。
3. 锁爪落入节距定位槽。
4. 推杆和转层梭在停歇段卸载。

不得把满排导向块硬推入没有接收空间的轨道。左右转层梭必须在横移前建立临时接收位。

## 6. 导向块数量冻结方法

原型图 3.24 明示编号 1 至 40，但缩放样机不能简单套用 `2n+2`。[PDF 图3.24: p5; p5.t20]

先建立三个状态占用表：

```text
N_block = occupied(S0) = occupied(S1) = occupied(S2)
```

每张表列出上排、下排、左梭、右梭及空接收位。只有证明三个状态占用恒定、编号连续循环且无重复占位后，才冻结块数。

## 7. 上下框架和层序

上、下框架本体固定并沿 `Z` 镜像安装。每框架含两排活动导向块，产生一对相反偏斜层；两个框架共四层。中央固定经纱导向板把经纱保持在相反偏斜层之间。[PDF p4.t3-p4.t7] [PDF p6.t3-p6.t10] [PDF 图3.25: p6; p6.t11]

四排在一次索引中的权威方向为：

| 固定框架 | 导向块排 | 横移方向 |
|---|---|---:|
| A40 上框架 | 上排 | `+Y × p` |
| A40 上框架 | 下排 | `-Y × p` |
| A41 下框架 | 上排 | `-Y × p` |
| A41 下框架 | 下排 | `+Y × p` |

A41 的 G-05L/G-06L 和 G-13L 相对 A40 的对应件为手性相反零件，不得以相同编号替代。表中方向用于定义当前完整周期的层符号；下一工位继续沿各自封闭循环运行，不表示框架本体平移。

## 8. 正传动链

```text
M1 偏斜索引伺服
→ 20:1 行星减速器
→ 扭矩限制离合器
→ 主索引轴
→ 上框架共轭凸轮
→ 下框架镜像凸轮
→ 上供纱链一步索引器
→ 反向齿轮副
→ 下供纱链一步索引器
```

一次索引只允许各排导向块移动一个节距、各偏斜供纱链移动一个筒子工位。导向块循环与供纱链不得使用相互独立、无机械对相的电机。

局部凸轮相位见 [07-timing-interlocks-and-control.md](07-timing-interlocks-and-control.md)，载荷和电机选型见 [06-transmission-interfaces-and-dynamics.md](06-transmission-interfaces-and-dynamics.md)。
