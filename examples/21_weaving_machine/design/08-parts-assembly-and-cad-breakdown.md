空间基准：[02-spatial-layout-and-envelopes.md](02-spatial-layout-and-envelopes.md)<br>

## 1. 文档用途

本文把系统方案转换为可建立 CAD 的总成树、零件几何合同、装配副、接口控制尺寸和装配顺序。它不冻结尚未试验的制造尺寸；材料、公差状态和验证门槛见 [09-materials-tolerances-and-validation.md](09-materials-tolerances-and-validation.md)。

## 2. CAD 建模规则

1. A/B/C/D 基准、`X_G`、`X_N`、`X_R`、`X_F=0` 和三个 `Z_fill` 平面由一个顶层骨架模型发布。
2. 子总成只引用已发布的基准、接口点和包络，不引用其他子总成的任意边或面。
3. 镜像总成共用参数；手性相反零件必须有独立编号，避免制造时误装。
4. 每个活动总成同时保存工作实体、运动副、机械零位和扫掠包络。
5. 标准件可简化螺纹和滚动体，但必须保留影响包络、质量、轴端、安装和维护的外形。
6. 纱线先建中心路径和禁入管，再在渲染或验证配置中生成实体纱束。
7. 工程建议参数集中在顶层参数表，不把相同数值复制到多个零件草图。

## 3. 顶层参数

| 参数 | 含义 | 初始值或关系 | 所有者 |
|---|---|---:|---|
| `W` | 有效织物宽度 | 288 至 300 mm | A00 骨架 |
| `p` | 导向块横向节距 | 12 mm | A40/A41 |
| `n` | 有效宽度位置数 | 25 | A00 骨架 |
| `s` | 每完整周期牵引步距 | `p/tan(θ)` | A90 |
| `H_fill` | 表层填充通道距中面 | 由层序和拉剑外廓确定 | A00 骨架 |
| `X_G` | 导向块出口平面 | `-380...-340 mm` | A00 骨架 |
| `X_N` | 粘合针插入平面 | `-280...-220 mm` | A00 骨架 |
| `X_R` | 拉剑横穿平面 | `-200...-120 mm` | A00 骨架 |
| `C_dyn` | 刚性活动件初始净间隙 | 不小于 5 mm | 包络模型 |
| `N_block` | 单框架导向块数 | 三状态占用表冻结 | A40/A41 |

表中坐标和间隙是 CAD 初始窗口，不是制造图尺寸。来源和空间关系见 [02-spatial-layout-and-envelopes.md](02-spatial-layout-and-envelopes.md)。

## 5. 零件几何合同

零件不得用无特征包络盒替代。下表特征是最低建模要求。

|---|---|---|---|

## 6. 总成接口控制

### 6.1 基准体系

| 基准 | 定义 | CAD 表达 |
|---|---|---|
| A | 主底架两条精加工基准梁的共面上平面 | 顶层基准面 |
| B | 织物宽度中心基准面 `Y=0` | 顶层基准面 |
| C | 织物中面 `Z=0` | 顶层基准面 |
| D | 织物成型基准面 `X=0` | 顶层基准面 |

安装件采用“一面、一圆销、一菱形销、夹紧螺栓”。圆销限制两个面内方向，菱形销只限制一个方向，避免温度变化造成过定位。

| 接口 | 主控特征 | 从属特征 | 调整方式 |
|---|---|---|---|
| A10/A90 | A、B、D | 双导轨中心、夹具中心 | 牵引架定位销和横向垫片 |
| A10/A40/A41 | A、B、C、`X_G` | 框架定位孔和出口眼平面 | 对称精密垫块 |
| A30/A40 | 机械零位和编号 | 链工位、导向块编号 | 相位胀套和编码板 |
| A31/A41 | 机械零位和编号 | 镜像链工位、导向块编号 | 反向齿轮和相位胀套 |

## 7. 装配副与自由度

| 连接 | 运动副 | 自由度 | 约束实现 |
|---|---|---:|---|
| A10 / 地基 | 固定副 | 0 | 地脚调平后锁紧 |
| 子总成 / A10 | 固定副 | 0 | 基准面、圆销、菱形销、夹紧螺栓 |
| 导向块 / 框架 | 分段移动副 | 1 | 直线段沿 `Y`，转层梭内沿 `Z` |
| 转层梭 / 框架 | 移动副 | 1 | 双导向面或微型直线导轨 |
| 推杆 / 框架 | 移动副 | 1 | 两个有足够跨距的轴套 |
| 凸轮 / M1 轴 | 固定副 | 0 | 胀套或键、端面锁紧、相位标记 |
| 滚轮 / 从动件轴 | 转动副 | 1 | 滚针轴承和轴向挡圈 |
| 筒子 / 芯轴 | 转动副 | 1 | 双轴承并叠加可控制动 |
| 针梁 / 导轨 | 移动副 | 1 | 两滑块跨距，只允许 `Z` 向 |
| 拉剑载板 / 导轨 | 移动副 | 1 | 双轨或单宽轨，只允许 `Y` 向 |
| 接合杆 1 / 门架 | 移动副 | 1 | 只允许 `Z` 向 |
| 接合杆 2 Z 台 / X 台 | 移动副 | 1 | 只允许 `Z` 向 |
| 接合杆 2 X 台 / 门架 | 移动副 | 1 | 只允许 `X` 向 |
| 筘 Z 台 / X 台 | 移动副 | 1 | 只允许 `Z` 向 |
| 筘 X 台 / 门架 | 移动副 | 1 | 只允许 `X` 向并闭合打纬反力 |
| 挂钩 / H-06 | 移动副 | 1 | 插入后只允许沿 `X` 移动 |
| 牵引座 / 双导轨 | 移动副 | 1 | 两侧滑块共同限制俯仰和偏航 |
| 丝杠 / 支承座 | 转动副 | 1 | 驱动端固定，远端浮动 |

CAD 约束不得通过零件恰好接触隐式形成。每个运动副只保留表中自由度，硬限位作为单独实体建模。

## 9. 尺寸链

### 9.1 `Y` 向宽度尺寸链

```text
B: Y=0
→ 上下框架定位销
→ 首个导向块中心
→ 全宽首末中心间的 `(n-1)` 个节距 `p`
→ 最外导向块中心
→ 左右挂钩中心
→ 筘有效边界
→ 牵引有效夹持边界
```

要求：

1. 上下框架共同从 `Y=0` 向两侧分配节距，不得分别从左边缘起算。
2. 挂钩中心按最外偏斜纱折叠线定位，不按外框定位。
3. 筘有效范围覆盖全部纱线，筘座避开挂钩路径。
4. 夹具覆盖全宽，并在挂钩导轨位置留缺口。

最外导向中心位置误差可写为：

```text
e_edge = e_frame + e_first + Σ(e_p,i)
```

采用统计公差时需保留最坏情况检查。调整垫片只能修正整体中心偏移，不能修正节距累计误差。

### 9.2 `Z` 向层高尺寸链

```text
C: Z=0
→ 中上/中下偏斜层
→ 中上/中下经纱层
→ 外侧偏斜层
→ 上/下表层填充通道
→ 上/下针行程端点
→ 上/下框架安装基准
```

要求：

1. 上下框架使用同一对称垫块族确定层高。
2. 三根拉剑高度由可更换精密垫片设定，不使用长孔目测调整。
3. 两组接合杆的三个槽分别对齐三个拉剑中心面。
4. 筘片工作边覆盖三通道，筘座刚性部分留在纱线包络外。
5. 上下针行程关于 `Z=0` 镜像。

通道一侧最小动态余量：

```text
C_rapier,min = C_nom - |e_frame| - |e_rail| - |e_shim| - |δ_rapier| - |δ_frame|
```

`C_rapier,min` 必须大于 [09-materials-tolerances-and-validation.md](09-materials-tolerances-and-validation.md) 冻结的验收下限。

### 9.3 `X` 向工艺尺寸链

```text
X_G
→ X_N
→ X_R 和纱圈释放区
→ 接合杆 2 捕获位
→ 筘打纬位
→ D: X=0
→ 挂钩导轨入口
→ 牵引夹具
```

该链同时控制：

1. 导向框架至成型线的纱线汇聚角。
2. 粘合纱最小弯曲半径和自由针长。
3. 接合杆 2 的水平行程。
4. 筘水平行程和织造门架深度。

任一工作平面改变后，必须重新生成纱线包络、接合杆路径和筘扫掠，不允许孤立移动单个子总成。

### 9.4 相位尺寸链

```text
M1 机械零槽
→ 上凸轮角度
→ 下镜像凸轮角度
→ 上链索引器工位
→ 反向齿轮
→ 下链索引器工位
→ 导向块编号锁定状态
```

相位链不是普通长度尺寸。装配图必须给出轴端标记、齿轮啮合标记、链工位编号和锁爪状态，维护后按 [07-timing-interlocks-and-control.md](07-timing-interlocks-and-control.md) 的 M1 零位恢复。

## 11. 装配顺序

1. 焊接 A11，消除应力，加工两条 A 基准梁和定位孔。
2. 安装 A14、T-01/T-02、双丝杠和 T-07/T-08，建立 B、C、D。
3. 安装 A13，相对牵引夹具建立织造门架中心和中面。
4. 安装 A40/A41，以同一组对称垫块校正 `X_G`、B、C 和节距镜像。
5. 安装中央固定经纱导向板和后部经纱导向板。
6. 安装 A30/A31 和 A42，连接两套链索引器与框架凸轮，完成链工位和导向块编号机械对相。
7. 安装 A50，使用检具调整 `X_N`、针列和安全退出高度。
8. 安装 A70 的 X 台、Z 台和筘盒，校正 D 和三通道覆盖范围。
9. 安装 A60、右侧填充导眼和填充供纱，校正 `X_R` 和三个 `Z_fill`。
10. 安装 A61，使用三层检具校正捕获槽和交接位。
11. 安装 A80，校正 `Y=±W/2`、导轨入口和末端回收口。
12. 安装轴端标记、硬限位、传感器靶和防护，不穿纱手动盘车。
13. 按 L0 至 L5 分级验证后再使用目标纤维。

## 12. 分级装配验收

| 层级 | 对象 | 进入下一层前必须通过 |
|---|---|---|
| L0 零件 | 导向块、针、钩头、筘片、挂钩 | 材料、关键尺寸、圆角、表面和标识 |
| L1 运动副 | 块/轨、梭/轨、滑台、丝杠 | 单自由度、全行程、间隙、摩擦、硬限位 |
| L2 子总成 | 框架、供纱链、A42 索引传动、针、拉剑、筘、牵引 | 独立空载和额定负载循环 |
| L3 配对 | 上下框架和链、拉剑和接合杆、接合杆和筘 | 对中、机械同步、局部干涉和载荷路径 |
| L4 织造区 | A40/A41、A50、A60/A61、A70 | 十步空载循环和动态净间隙 |
| L5 整机 | A20 至 A90 | 张力、控宽、牵引和完整织物单元 |

任一 L2 总成自身不能稳定完成全行程时，不得用整机控制偏置掩盖机械问题。量化验收项目见 [09-materials-tolerances-and-validation.md](09-materials-tolerances-and-validation.md)。

## 13. 图纸和 BOM 输出

每个总成发布包至少包含：

1. 装配图、爆炸图和带版本的 BOM。
2. A/B/C/D 或从属基准引用。
3. 运动副、自由度、零位和硬限位。
4. 接口控制尺寸和公差状态。
5. 润滑、紧固、防松和维护说明。
6. 质量、质心和惯量，供 [06-transmission-interfaces-and-dynamics.md](06-transmission-interfaces-and-dynamics.md) 校核。
7. `HOME`、关键工艺姿态和扫掠包络的轻量模型。
8. 纱线接触零件的材料、表面、圆角和清洁要求。

## 14. CAD 完成定义

只有以下条件全部满足，A00 才可从概念 CAD 转入加工图：

1. `N_block` 三状态占用表闭合，A40/A41 无重复占位或空接收位错误。
2. A42 向 A30/A31 与 A40/A41 发布的相位链在完整循环中保持一一对应。
3. M1 至 M10 的运动副、零位、硬限位和扫掠包络已建立。
4. 所有刚性件在额定挠度下仍满足动态间隙。
5. X/Y/Z 和相位尺寸链均有唯一公差所有者及可调项。
6. 所有维护件可在 `SERVICE` 配置中拆卸，且不需要拆主门架。
7. [09-materials-tolerances-and-validation.md](09-materials-tolerances-and-validation.md) 中加工图冻结门槛已经通过。
