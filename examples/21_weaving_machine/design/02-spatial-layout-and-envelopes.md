## 1. 坐标与原点

定义名义中面成型线的宽度中心为 `O(0,0,0)`：

- `X=0`：填充纱被筘压实的成型基准面 D；名义中面成型线为 D 与 `Z=0` 的交线。
- `Y=0`：有效织物宽度中心基准面 B。
- `Z=0`：织物中面和中间填充通道中心面。
- `X<0`：导向框架及供纱侧。
- `X>0`：成品织物及牵引侧。
- `Y<0`：拉剑初始侧。
- `Y>0`：填充纱筒子及拾纱侧。

## 2. `X` 向工作站链

关键工艺平面必须按下列顺序布置：

```text
供纱整理平面
< 偏斜导向块出口 X_G
< 粘合针插入平面 X_N
< 拉剑横穿平面 X_R
< 织物成型线 X_F=0
< 牵引夹具工作区 X_T
```

图 3.31 显示纱线由导向块向成型线汇聚，针、填充通道和筘位于其间，这些机构不能重合在一个无厚度平面。[PDF p10.t3-p10.t17] [PDF 图3.31: p10; p10.t18]

300 mm 样机的 CAD 初始窗口：

| 平面或区域 | 建议 `X` 范围 | 作用 |
|---|---:|---|
| 导向块出口 `X_G` | `-380...-340 mm` | 偏斜纱和中央经纱的出口基准 |
| 筘后下安全位 | `-330...-280 mm` | 避开导向块运动包络 |
| 粘合针平面 `X_N` | `-280...-220 mm` | 控制粘合纱弯曲曲率 |
| 拉剑平面 `X_R` | `-200...-120 mm` | 三个填充通道 |
| 接合杆 2 后位 | `-250...-180 mm` | 捕获拉剑释放的纱圈 |
| 筘打纬位 | `-10...0 mm` | 到达但不越过成型线 |
| 接合杆 1 | `-10...+10 mm` | 保持成型线处填充纱 |
| 挂钩插入平面 | `0...+15 mm` | 定义偏斜纱折叠边界 |
| 牵引夹具 | `+300...+1400 mm` | 按样品长度确定 |

这些是建立骨架模型的窗口，不是制造尺寸。正式位置由弯曲半径、针长、拉剑外廓、筘行程和避碰分析共同冻结。

## 3. `Y` 向宽度关系

若有 `n` 个有效导向位置、节距为 `p`：

```text
Y_i = [i - (n - 1) / 2] × p,  i=0...n-1
```

当 `n=25`、`p=12 mm` 时，最外中心为 `±144 mm`，中心跨度为 288 mm。

| 宽度区域 | `Y` 关系 | 允许内容 |
|---|---:|---|
| 有效纱线区 | `-W/2...+W/2` | 纱线、拉剑、针、筘片、接合指爪 |
| 左右挂钩 | `约 ±W/2` | 偏斜纱折叠点 |
| 拉剑左安全区 | `< -W/2-C_L` | 钩头及驱动载板原点 |
| 右侧拾纱区 | `> +W/2+C_R` | 三个填充导眼 |
| 门架支承区 | `|Y| > W/2+C_S` | 立柱、导轨座和防护 |

初始取 `C_L,C_R≥80 mm`，动态载板侧建议不小于 120 mm。最外导向块中心、挂钩中心、筘有效边界和夹具宽度必须从共同中心线标注。

## 4. `Z` 向层间关系

三个填充通道关于 `Z=0` 对称：

```text
Z_fill_top = +H_fill
Z_fill_mid = 0
Z_fill_bottom = -H_fill
```

通道净高需满足：

```text
H_shed >= D_rapier + 2C_rapier + ΔH_yarn
```

- `D_rapier`：拉剑厚度方向最大外廓。
- `C_rapier`：单侧动态间隙。
- `ΔH_yarn`：毛羽、张力波动及叠纱裕量。

从上到下的层级：

```text
上针安全原点
上偏斜导向框架
上表层填充通道
上部经纱与两层偏斜纱
中间填充通道 Z=0
下部两层偏斜纱与经纱
下表层填充通道
下偏斜导向框架
下针安全原点
```

依据见图 3.25、图 3.26 和图 3.31。[PDF 图3.25: p6; p6.t11] [PDF 图3.26: p6; p6.t33] [PDF 图3.31: p10; p10.t18]

## 5. 纱线锥形包络

任一导向点 `P_G` 到成型点 `P_F` 的名义路径：

```text
P(λ) = P_G + λ(P_F-P_G),  0<=λ<=1
```

名义路径周围的禁入半径：

```text
R_keepout = R_bundle + ΔR_motion + C_guard
```

`ΔR_motion` 包含导向块索引、张力摆臂释放和纱线振动。至少建立以下代表纱线扫掠体：

1. 上框架最外侧 `+θ` 和 `-θ` 纱。
2. 下框架最外侧 `+θ` 和 `-θ` 纱。
3. 上、中、下三个填充纱圈。
4. 两侧 Z 向粘合纱。
5. 牵引前最低张力和牵引后最高张力状态。

## 7. 机构禁入矩阵

| 机构对 | 同时运动 | 约束 |
|---|---|---|
| 导向块 / 针 | 禁止 | 针完全退出 E-G |
| 导向块 / 筘 | 禁止 | 筘在后下安全位 |
| 导向块 / 拉剑 | 禁止 | 拉剑退出有效宽度 |
| 拉剑 / 针 | 禁止 | 针达到避让高度 |
| 拉剑 / 筘 | 禁止 | 筘不进入填充通道 |
| 接合杆 2 / 筘 | 条件允许 | 按已验证轨迹保持固定先导距离 |
| 接合杆 2 / 拉剑 | 条件允许 | 拉剑释放纱圈后再进入捕获位 |
| 挂钩 / 导向块 | 顺序允许 | 先插钩并退出推杆，再偏斜索引 |
| 牵引 / 织造机构 | 禁止 | 所有侵入件回安全位 |

刚性活动件初始动态净间隙取不小于 5 mm。工艺接触位置除外，最终数值需加上结构挠度和伺服跟随误差。

## 8. 机架空间和基准

主机架分供纱架、织造门架和牵引架，统一安装在两条精加工基准梁上。总体外形关系依据图 3.20。[PDF 图3.20: p2; p2.t9]

| 基准 | 定义 |
|---|---|
| A | 主底架精加工梁上平面 |
| B | 织物宽度中心基准面 `Y=0` |
| C | 织物中面 `Z=0` |
| D | 织物成型基准面 `X=0` |

O 为 B、C、D 三个基准面的交点。所有导向孔、针、拉剑、筘、挂钩和夹具都相对 A/B/C/D 定位。禁止各总成按外框边缘独立找正。

机架参考截面：底架 `80×40×4 mm`，门架 `60×60×4 mm`。焊接后消除应力，再加工安装面。纱线包络内不得出现裸露螺纹、锐边和焊缝。

装配尺寸链见 [08-parts-assembly-and-cad-breakdown.md](08-parts-assembly-and-cad-breakdown.md)，时序禁入条件见 [07-timing-interlocks-and-control.md](07-timing-interlocks-and-control.md)。
