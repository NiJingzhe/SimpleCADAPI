# 粘合针、填充插入、交接与打纬机构

## 1. 织造区任务链

织造区按以下任务顺序工作：

```text
偏斜纱索引并锁定
→ 三个填充通道形成
→ 拉剑穿入并拾取填充纱
→ 拉剑回程形成三只纱圈
→ 接合杆捕获和保持纱圈
→ 开放式筘把填充纱压到成型线
→ 粘合针换位形成 Z 向锁合
→ 重复第二次填充和打纬
```

机构时序见 [07-timing-interlocks-and-control.md](07-timing-interlocks-and-control.md)。

## 2. 粘合针总成

PDF 明示使用一端固定的针具使粘合纱在经纱和偏斜纱之间上下移动；两组针位于织物两面并交替排列。[PDF p6.t12-p6.t16] [PDF p6.t21-p6.t32] [PDF 图3.26: p6; p6.t33]

### 2.1 独立零件

| 编号 | 零件 | 几何与任务 |
|---|---|---|
| N-01 | 上针夹梁 | 箱形或梳形梁，分段针槽和独立压板 |
| N-02 | 下针夹梁 | 上针梁镜像，横向错位半个针距 |
| N-03 | 粘合针 | 细长抛光针体、圆钝针尖、针眼、夹持扁位 |
| N-04 | 陶瓷衬眼 | 降低粘合纱摩擦 |
| N-05/N-06 | 上下滑台 | 双导轨支承，仅允许 `Z` 向移动 |
| N-07 | 恒力回收器 | 每根纱独立恒力弹簧或配重 |
| N-08 | 针位微调座 | 沿 `X/Z` 微调插入点和深度 |
| N-09 | 软限位 | 超程时保护针和导向块 |
| N-10 | 状态检测 | 上位、下位、安全退出位 |

### 2.2 传动

```text
M2
→ 低背隙减速器
→ 主动同步带轮
→ 双面同步带
→ 上针滑块
→ 反向夹持段
→ 下针滑块
```

上下针梁反向同步。针夹梁不得进入纱线汇聚包络，只有针体穿过织造区。

### 2.3 插入几何

偏斜纱横移后形成针的可用间隙。针过于靠近导向块会使玻纤产生过小弯曲半径并断裂。[PDF p6.t17-p6.t20] [PDF 图3.27: p7; p7.t15-p7.t16] [PDF 图3.28: p7; p7.t21]

最低几何条件：

```text
g_cross > d_needle + 2c
R_yarn >= R_min_material
```

- `g_cross`：偏斜纱交叉间隙。
- `d_needle`：针最大外径。
- `c`：单侧安全间隙。
- `R_min_material`：目标纱束允许最小弯曲半径。

针还需验算意外碰纱时的屈曲：

```text
P_cr = π²EI / (K L)²
```

`E` 为针材弹性模量，`I` 为针截面二次矩，`L` 为针夹至首次可靠侧向支承之间的无支承长度。意外碰纱按保守的固定-自由悬臂取有效长度系数 `K=2`；若试验能证明针尖存在可靠侧向支承，才可重新评估。正常插入力应显著低于 `P_cr`。优先缩短自由针长，不使用过长针补偿装配距离。

## 3. 三层拉剑总成

PDF 使用带钩头拉剑横跨织物宽度，拾取填充纱后回程形成双股纱圈。三根拉剑固定在同一垂直载件上，对应上、中、下三个填充通道。[PDF p7.t22-p7.t28] [PDF p8.t3-p8.t8] [PDF p8.t19-p8.t25] [PDF 图3.29: p8; p8.t26]

### 3.1 独立零件

| 编号 | 零件 | 几何与任务 |
|---|---|---|
| R-01/R-02/R-03 | 上、中、下拉剑轴 | 碳纤管或薄壁铝梁，前端具有 R-07 安装止口 |
| R-04 | 垂直载板 | 箱形根部连接，固定三个层高 |
| R-05 | 双线性导轨 | 大跨距支承，限制载板扭转 |
| R-06 | HTD 同步带 | 长行程高速往复 |
| R-07 | 可换钩头，数量 3 | 316L 不锈钢精抛，具有钩口、释放斜面和圆钝外廓 |
| R-08 | 三个填充导眼 | 位于右侧拾纱区，与钩头高度对中 |
| R-09 | 三套填充张力器 | 独立供纱和张力补偿 |
| R-10 | 缓冲和硬限位 | 位于左右行程端 |

### 3.2 行程

```text
L_rapier >= W + C_L + C_R
```

`C_L` 包含左侧完全退出和载板包络，`C_R` 包含右侧导眼和可靠钩纱裕量。按 [02-spatial-layout-and-envelopes.md](02-spatial-layout-and-envelopes.md) 的当前窗口，动态载板侧取 120 mm、拾纱侧取 80 mm 时，288 至 300 mm 有效宽度对应的初始行程下限为 488 至 500 mm。最终行程在 R-08 位置和钩头啮合长度冻结后计算，不再独立套用固定范围。

### 3.3 传动和刚度

```text
M3
→ 主动同步带轮
→ 闭合 HTD 同步带
→ 载板夹块
→ 三根拉剑同步往复
```

使用双导轨或单宽轨。三根剑杆根部形成箱形连接，避免只夹在薄板边缘。驱动力：

```text
F_rapier = m_move a + F_belt + F_guide + F_pickup
```

拾纱和释放区设置低速平台，其他行程使用限加加速度 S 曲线。

## 4. 接合杆 1

接合杆 1 位于成型线附近，只做 `Z` 向运动，用于保持上一根填充纱并接收新纱。[PDF p7.t24-p7.t28]

| 零件 | 几何 |
|---|---|
| 横梁 | 跨越三个层高的刚性梁 |
| 指爪 | 三个独立圆角夹持槽 |
| 高度垫片 | 分别调整三个指爪中心 |
| 升降滑台 | 双导柱或微型直线导轨 |
| 驱动 | M4 短丝杠或伺服曲柄 |

接合杆 1 不做长距离前后运动，也不承担主要打纬力。

## 5. 接合杆 2

接合杆 2 位于拉剑相对侧，需要 `Z` 向捕获和 `X` 向送纱两种运动。[PDF p7.t24-p7.t28]

| 轴 | 驱动 | 功能 |
|---|---|---|
| `Z` | M5 短滚珠丝杠 | 从后下位升到纱圈释放高度 |
| `X` | M6 滚珠丝杠 | 从导向框架前方移动到成型线 |

横梁具有三个朝拉剑回程方向开口的捕获槽。槽底为大圆角，三个槽用垫片独立调整高度。

## 6. 纱圈交接

PDF 的五步填充过程见图 3.30。[PDF p8.t8-p8.t17] [PDF 图3.30: p9; p9.t11]

机械落实为：

1. 接合杆 1 在成型线保持上一根填充纱。
2. 接合杆 2 位于导向框架前方的低位。
3. 拉剑回程并释放三只纱圈。
4. 接合杆 2 上升捕获纱圈。
5. 接合杆 2 沿 `+X` 向成型线移动。
6. 开放式筘保持固定先导距离同步前进。
7. 接合杆 1 下降释放旧纱，再上升夹持新纱。
8. 接合杆 2 下降并后退。

## 7. 开放式筘

传统闭合筘会困住每周期横移的偏斜纱。PDF 采用筘片单侧固定的开放式筘，并规定上升、前进、下降、后退四步矩形路径。[PDF p10.t20-p10.t36] [PDF p11.t3-p11.t7] [PDF 图3.32: p11; p11.t8]

### 7.1 独立零件

| 编号 | 零件 | 几何与任务 |
|---|---|---|
| D-01 | 筘座 | 高惯性矩箱形铝梁，传递打纬反力 |
| D-02 | 开放筘片 | `0.4...0.8 mm` 弹簧不锈钢薄片，单端固定 |
| D-03 | 夹板 | 用定位齿和螺栓固定筘片节距 |
| D-04 | 可换筘盒 | 整套筘片快速拆换 |
| D-05 | `X` 滑台 | 宽跨距导轨承受打纬力 |
| D-06 | `Z` 滑台 | 只承担升降和筘自重 |
| D-07/D-08 | M8/M7 丝杠驱动 | 分别负责水平打纬和垂直进出 |
| D-09 | 力传感器 | 检测异常打纬阻力 |
| D-10 | 硬限位 | 防止撞击导向块和成型夹具 |

### 7.2 路径

```text
P0 后下安全位
→ P1 垂直上升，进入偏斜纱交叉间隙
→ P2 水平前进，到达成型线并打纬
→ P3 垂直下降，完全退出织造区
→ P0 水平后退
```

`Z` 轴不承担主要 `X` 向打纬反力。力流应从筘片、筘座、`X` 滑台直接闭合到织造门架。

打纬总弹性位移初始目标：

```text
δ_reed_total <= 0.10 mm
```

## 8. 织造区装配接口

| 接口 | 基准和配合 |
|---|---|
| 针梁 / 门架 | 双导轨移动副，针平面相对 `X_N` 定位 |
| 拉剑 / 门架 | 双导轨移动副，三个钩头相对三个 `Z_fill` 平面对中 |
| 接合杆 1 / 成型线 | 只允许 `Z` 向，三个指爪相对拉剑高度对中 |
| 接合杆 2 / 复合台 | `X-Z` 串联移动副，后位和成型线位均有硬限位 |
| 筘 / 门架 | `X-Z` 串联移动副，筘片有效宽度相对 `Y=0` 对称 |

所有子总成必须先单独完成全行程，再按 [02-spatial-layout-and-envelopes.md](02-spatial-layout-and-envelopes.md) 的禁入矩阵进行织造区联调。
