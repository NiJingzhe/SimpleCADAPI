## 1. 宽度收缩机理

多轴织物边缘的偏斜纱在供纱张力和牵引作用下折叠，产生指向中心的收缩力。厚多层织物不能只靠普通边撑维持宽度，固定筘距还可能加剧摩擦和密度不均。[PDF p11.t9-p11.t23] [PDF 图3.33: p12; p12.t9] [PDF 图3.34: p12; p12.t19]

因此任务分为两个独立系统：

- 边缘挂钩定义左右偏斜纱折叠位置和成型宽度。
- 直线牵引夹具只提供 `X` 向步进位移和纵向张力。

牵引夹具不能替代挂钩控宽，挂钩也不承担牵引驱动力。

## 2. 周期边缘挂钩

PDF 明示每个周期在左右边缘最后两根偏斜纱之间各插入一个挂钩；新挂钩通过特殊导轨和旧挂钩配合，并随织物移动。[PDF p11.t24-p11.t28] [PDF p12.t3-p12.t4] [PDF p13.t3-p13.t9] [PDF 图3.35: p13; p13.t10]

### 2.1 独立零件

| 编号 | 零件 | 几何与任务 |
|---|---|---|
| H-01/H-02 | 左右挂钩 | 镜像 J 形件，圆角纱线鼻部和导轨捕获脚 |
| H-03/H-04 | 左右料匣 | 竖直弹簧料匣，每次释放一只 |
| H-05 | 插入滑块 | 短行程伺服凸轮或丝杠 |
| H-06 | C 形导轨 | 捕获挂钩脚并允许沿 `X` 滑动 |
| H-07 | 同步横轴 | 机械同步左右插入 |
| H-08 | 缺钩传感器 | 检查料匣和插入结果 |

挂钩采用 316L 精抛或 PEEK。与纱线接触的鼻部无锐边，最小圆角由目标纱束弯曲试验确定。

### 2.2 工作过程

1. 织造区所有活动件退到安全位。
2. 左右料匣各释放一只挂钩。
3. 同步横轴驱动左右滑块插入挂钩。
4. 挂钩头进入最外两根偏斜纱之间，捕获脚进入 C 形导轨。
5. 插入滑块完全退出纱线区。
6. 偏斜导向块索引，边缘纱绕新挂钩折叠。
7. 周期末牵引时，新旧挂钩沿导轨共同前进。
8. 到达末端后人工或自动回收挂钩。

挂钩插入位置相对 `Y=±W/2` 定位，不相对机架外边定位。

## 3. 挂钩导轨

C 形导轨沿 `X` 固定在牵引架两侧，几何包含：

| 特征 | 任务 |
|---|---|
| 入口喇叭口 | 允许新挂钩插入并进入通道 |
| 封闭捕获段 | 限制挂钩脱落和横向旋转 |
| 纵向滑动面 | 让挂钩随织物前进 |
| 末端拆卸口 | 回收旧挂钩 |
| 安装调节孔 | 校正左右导轨间距和高度 |

导轨不得夹紧挂钩形成牵引副；挂钩由织物带动，导轨只约束姿态和宽度。

## 4. 直线牵引必要性

PDF 指出厚多层织物不适合传统旋转卷布，因此使用夹具和长螺纹杆做直线牵引。[PDF p12.t5-p12.t7] [PDF 图3.35: p13; p13.t10]

工程方案把单螺杆改为单电机、双导轨、双丝杠机械同步，避免全宽夹具偏航。

## 5. 牵引总成

| 编号 | 零件 | 几何与任务 |
|---|---|---|
| T-01/T-02 | 左右直线导轨 | 支承全宽夹具，限制俯仰和偏航 |
| T-03/T-04 | 左右滚珠丝杠 | 建议 5 或 10 mm 导程 |
| T-05 | 同步横轴 | 两组锥齿轮机械同步双丝杠 |
| T-06 | M10 抱闸伺服 | 提供牵引和失电保持 |
| T-07/T-08 | 上下夹爪 | 箱形全宽梁和分段柔性夹垫 |
| T-09 | 夹紧机构 | 多点螺旋、液压或偏心夹紧 |
| T-10 | 左右位置尺 | 检测夹具偏斜 |

### 5.1 传动链

```text
M10
→ 行星减速器
→ 带抱闸输入轴
→ 左丝杠
→ 同步横轴和锥齿轮
→ 右丝杠
→ 左右螺母座
→ 全宽夹具
```

两个独立电机的软件同步不能替代机械同步。掉电或单轴报警时，机械横轴保持左右位置关系。

### 5.2 丝杠支承

- 驱动端使用固定轴承组承受双向轴向力。
- 远端使用浮动支承，允许热伸长。
- 左右丝杠螺母座与同一刚性横梁连接。
- 双导轨滑块跨距尽量大，夹具质心位于导轨支承多边形内。

## 6. 夹具几何与压力

上下夹爪使用高惯性矩箱形梁，接触面分段布置聚氨酯或软铝夹垫。夹垫需要：

1. 覆盖全宽但避开两侧挂钩导轨。
2. 对厚度不均具有局部顺应性。
3. 不把纱束压碎或推动层间错移。
4. 可单段更换。

夹持条件：

```text
μ N_clamp >= F_takeup × K_s
```

同时接触压力不得超过目标预制体允许值。需要用实际织物样片测试摩擦系数和压实变形。

## 7. 牵引力流

```text
M10
→ 双丝杠
→ 全宽夹具
→ 已成型织物
→ 经纱、偏斜纱、粘合纱张力
→ 各张力器和供纱架
→ 主底架
```

供纱架、织造门架和牵引架必须连接在同一底架上，形成闭合载荷路径。

## 8. 运动和时序

牵引只在以下条件全部满足时执行：

1. 第二次打纬完成。
2. 拉剑退出有效宽度。
3. 粘合针处于安全状态。
4. 筘在后下位。
5. 接合杆 2 在后下位。
6. 挂钩已进入导轨。
7. 上下导向块保持锁定。

夹具前进一个步距 `s`，张力器被动释放所需纱长。`s` 与偏斜索引节距共同决定角度，关系见 [01-process-and-system-architecture.md](01-process-and-system-architecture.md)。

## 9. 有限行程和连续生产

首台验证机使用单夹具有限行程，便于观察织物结构。连续生产需要两个交替夹具：

1. 主夹具夹持并前进。
2. 次夹具在成型线后方接管载荷。
3. 主夹具松开、回程并重新夹持。
4. 两夹具交替，但任何时刻至少一套承载织物张力。

双夹具是后续扩展，不属于首台样机最低闭环。
