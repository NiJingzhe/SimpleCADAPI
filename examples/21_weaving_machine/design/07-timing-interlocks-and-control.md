## 1. 时序依据

PDF 的周期从插入左右边钩开始，随后偏斜纱索引，完成两次填充、打纬与粘合，最后直线牵引。[PDF p13.t21-p13.t29] [PDF p14.t3-p14.t28] [PDF p15.t3-p15.t27] [PDF 图3.36: p15; p15.t28]

本方案使用离散状态机和虚拟主轴相位。相位用于协调，不代表所有轴都由一根连续旋转机械主轴驱动。

## 2. 虚拟主周期 `Φ`

| `Φ` | 状态 | 主要运动 | 必须退出的机构 |
|---:|---|---|---|
| `0°...20°` | 初始化和插钩 | M9 左右挂钩插入 | 导向块、拉剑、针、筘、牵引 |
| `20°...70°` | 偏斜索引 | M1 局部凸轮循环及上下供纱链 | 拉剑、针、筘、接合杆 2、牵引 |
| `70°...115°` | 第一次拉剑穿入 | M3 左到右，接合杆 1 保持 | 针、筘、导向块、牵引 |
| `115°...150°` | 第一次回程 | M3 带回纱圈，接合杆 2 准备 | 针、筘前进轴、导向块、牵引 |
| `150°...190°` | 第一次打纬 | 接合杆 2 和筘进入，接合杆 1 换持 | 拉剑、导向块、牵引 |
| `190°...220°` | 退出和针换位 | 筘下降、接合杆后退、M2 换位 | 拉剑、导向块、牵引 |
| `220°...265°` | 第二次拉剑穿入 | M3 再次左到右 | 筘、导向块、牵引 |
| `265°...300°` | 第二次回程 | M3 带回第二组纱圈 | 筘前进轴、导向块、牵引 |
| `300°...335°` | 第二次打纬 | 筘和接合杆完成第二次锁合 | 拉剑、导向块、牵引 |
| `335°...360°` | 退出和牵引 | 所有织造件退出，M10 前进 `s` | 导向块、拉剑、针、筘、接合杆 |

每段必须由到位条件结束，不由固定时间强制跳转。提前完成的轴在安全位等待；超时未完成则保持当前离散状态并报警。

## 3. 导向块局部凸轮 `φ_G`

主相位 `20°...70°` 内，M1 完成一次局部 `0°...360°` 循环：

| `φ_G` | 任务 | 机构状态 |
|---:|---|---|
| `0°...30°` | 解锁 | 锁爪抬起，推杆保持预载 |
| `30°...90°` | 捕获端块 | A40 左提升/右下降梭、A41 左下降/右提升梭进入接收位 |
| `90°...210°` | 横移和转层 | A40 上/下排 `+p/-p`，A41 上/下排 `-p/+p`，端块换层 |
| `210°...270°` | 完全入位 | 转层梭送入，随动杆校正块链 |
| `270°...320°` | 锁定 | 定位锁爪落入节距槽 |
| `320°...360°` | 停歇确认 | 推杆卸载，检查供纱链和块编号 |

图 3.23 和图 3.24 是该局部时序的几何证据。[PDF 图3.23: p5; p5.t10] [PDF 图3.24: p5; p5.t20]

凸轮要求：

1. `0°/360°` 位移、速度和加速度连续。
2. 端块进入和退出转层梭时低速。
3. 横移全过程锁爪完全抬起。
4. 供纱链制动仅在锁爪确认完全抬起后释放，并在锁爪开始落下前重新接合。
5. 供纱链在 `90°...270°` 内完成一工位索引并确认制动已重新接合。

## 4. 两次填充子循环

| 子循环 | 拉剑 | 筘 | 粘合针 | 输出 |
|---|---|---|---|---|
| Filling A | 左安全位 → 右拾纱位 → 左释放位 | 后下 → 上 → 前 → 下 → 后 | 初始位，打纬后换位 | 第一组三层填充纱 |
| Filling B | 同一几何路径 | 同一几何路径 | 相反位，周期末锁合 | 第二组三层填充纱 |

两次填充之间不牵引、不索引偏斜纱。只有 Filling B 完成并退出后才牵引。

## 5. 十步机械动作

### 5.1 第 1 步：插入边钩

1. 拉剑回左安全位。
2. 针处于安全位。
3. 筘处于后下位。
4. 接合杆 2 处于后下位。
5. 左右挂钩插入并进入导轨。

### 5.2 第 2 步：偏斜索引

1. M1 解锁导向块。
2. 左右转层梭捕获端块。
3. A40/A41 框架本体保持固定，四排导向块按 03 的方向表各移动 `p`。
4. 上下供纱链同步反向各前进一工位。
5. 端块进入另一排，锁爪落下。

供纱链同步防止筒子到导向块之间缠绕。[PDF p14.t3-p14.t4]

### 5.3 第 3 步：第一次穿入

1. 接合杆 1 保持上一根填充纱。
2. 接合杆 2 在后下位。
3. 三根拉剑穿过上、中、下三个通道到右侧拾纱区。

### 5.4 第 4 步：第一次回程

1. 三个钩头拾取三根填充纱。
2. 拉剑返回左侧形成三只双股纱圈。
3. 接合杆 2 上升捕获纱圈。
4. 筘上升进入偏斜纱间隙。

### 5.5 第 5 步：第一次打纬

1. 筘和接合杆 2 保持固定先导距离向成型线移动。
2. 筘压实三层填充纱。
3. 接合杆 1 下降释放旧纱，再上升保持新纱。

### 5.6 第 6 步：退出和针换位

1. 筘下降。
2. 接合杆 2 下降并后退。
3. 上下粘合针反向换位。
4. 恒力回收器吸收多余粘合纱。

### 5.7 第 7 步：第二次穿入

1. 筘水平回后位。
2. 确认针到允许位置。
3. 三根拉剑再次穿过三个通道。

### 5.8 第 8 步：第二次回程

1. 拉剑带回第二组三只纱圈。
2. 接合杆 2 上升捕获。
3. 筘再次上升。

### 5.9 第 9 步：第二次打纬和锁合

1. 筘和接合杆 2向成型线移动。
2. 第二组填充纱被压实。
3. 接合杆 1 完成交接。
4. 粘合针达到周期锁合状态。
5. 所有织造机构依次退出。

### 5.10 第 10 步：牵引

1. 确认所有侵入件处于安全位。
2. M10 使夹具前进 `s`。
3. 张力器释放对应纱长。
4. 左右挂钩沿导轨前进。
5. 到位后开始下一周期。

## 6. 允许并行动作

1. 拉剑回程后段可与接合杆 2 上升准备部分重叠，但不能进入拉剑刚性包络。
2. 接合杆 2 向成型线移动可与筘前进同步，两者保持固定先导距离。
3. 筘下降可与接合杆 2 下降同步，接合杆后退等待筘片离开。
4. 粘合纱回收摆臂可在针运动中被动动作。
5. 牵引过程中张力器被动放纱。

禁止组合见 [02-spatial-layout-and-envelopes.md](02-spatial-layout-and-envelopes.md) 的禁入矩阵。

## 7. 轴零位

| 轴 | 机械零位 |
|---|---|
| M1 | 锁爪落下、推杆卸载、链条编号与导向块对齐 |
| M2 | 上下针不侵入拉剑和筘路径 |
| M3 | 三根拉剑完全退出有效宽度 |
| M4 | 接合杆 1 保持旧纱的上位 |
| M5/M6 | 接合杆 2 后下位 |
| M7/M8 | 筘后下位 |
| M9 | 挂钩推杆完全退出，下一挂钩待料 |
| M10 | 夹具样品起始位，左右差为零 |

维护后先建立机械零位，再连接同步带和联轴器，最后穿纱。禁止带纱强行对相。

## 8. 必要互锁

| 动作 | 允许条件 |
|---|---|
| 导向索引 | 拉剑、针、筘、接合杆 2 全退出 |
| 拉剑穿入 | 锁爪到位，三个通道无遮挡 |
| 筘上升 | 拉剑退回，偏斜索引结束 |
| 筘前进 | 接合杆 2 已捕获纱圈，针在允许高度 |
| 针换位 | 筘下降，拉剑不在通道 |
| 挂钩后偏斜索引 | 挂钩进入导轨，插入滑块已退出 |
| 牵引 | 所有织造机构安全，第二次打纬完成 |
| 下一周期 | 上下链工位、导向块编号和牵引位置一致 |

## 9. 故障状态

| 故障 | 机械响应 |
|---|---|
| 导向块扭矩超限 | 离合器打滑，M1 停止，不自动反复冲击 |
| 拉剑不到位 | 筘和针保持退出，不交接 |
| 筘力超限 | 水平停止，优先下降后退 |
| 针不到位或弯曲 | 禁止拉剑和牵引 |
| 断纱 | 保持当前离散工位，允许人工接纱 |
| 链条和导向块错相 | 禁止索引，机械重新对相 |
| 左右牵引差超限 | M10 抱闸，禁止继续 |
| 挂钩缺料 | 禁止偏斜换位 |
| 急停 | 各轴按无碰撞优先级减速，抱闸保持重力轴和牵引轴 |

故障恢复不得直接执行“全部回原点”。应根据当前包络选择安全退出顺序。
