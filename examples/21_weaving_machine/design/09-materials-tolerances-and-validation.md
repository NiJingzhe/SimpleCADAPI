## 1. 状态规则

本文把数值分为三种状态：

| 状态 | 含义 | 能否进入加工图 |
|---|---|---|
| PDF 明示 | 原文或图直接给出的结构、数量、动作或顺序 | 可以作为功能要求 |
| 工程建议 | 用于首轮 CAD、采购级别和试验设计的初值 | 不可以直接冻结 |
| 已验证 | 有计算、材料数据或实测记录支持，并完成评审 | 可以按评审范围冻结 |

根据 [00-evidence-and-terminology.md](00-evidence-and-terminology.md) 记录的 15 页全文核对边界，原 PDF 没有给出精确轴径、载荷、材料牌号、速度和公差。所有工程建议值必须通过本文的测试闭环后才能转为已验证值。

## 2. 使用环境和材料相容性

设计输入至少记录：

1. 目标纤维：玻纤、碳纤或芳纶及具体束规格。
2. 是否带上浆、上浆剂类型及允许清洗剂。
3. 温度、相对湿度和粉尘浓度范围。
4. 允许使用的润滑剂和禁止污染区域。
5. 静电接地要求，碳纤粉尘环境还需评估导电污染。

纱线接触区禁止裸露油脂、含硅脱模剂、锐边、毛刺、焊渣和未封闭螺纹。聚合物零件需验证吸湿、蠕变、上浆剂和清洁剂相容性。

## 3. 材料和表面建议

| 零件类别 | 候选材料 | 表面和工艺 | 冻结前验证 |
|---|---|---|---|
| 主底架和门架 | Q235B 或 S355 | 喷砂、底漆、面漆；基准面后加工 | 焊后变形、刚度、涂层附着 |
| 精密框板 | 6061-T6；高载荷区可用 7075-T6 | 非纱线接触区硬质阳极氧化 | 平面度、槽磨损、涂层脱落风险 |
| 导向块 | PEEK、POM-H 或耐磨含油塑料 | 去毛刺、低粗糙度、永久编号 | 吸湿、蠕变、粉尘摩擦和寿命 |
| 导向耐磨条 | UHMW-PE、PEEK 或锡青铜 | 可更换、端部导入圆角 | 摩擦、磨损、热伸长 |
| 陶瓷导眼 | 高纯氧化铝 | 镜面级孔口圆角 | 崩边、纱线磨损和压装可靠性 |
| 粘合针 | 17-7PH 或弹簧不锈钢 | 热处理后电解抛光 | 屈曲、疲劳、针眼磨损 |
| 拉剑梁 | 碳纤管或高强铝薄壁梁 | 根部粘接/夹持面受控 | 挠度、固有频率、接头疲劳 |
| 拉剑钩头 | 316L | 精抛、圆钝、可更换 | 钩纱可靠性和磨损 |
| 筘片 | 弹簧不锈钢 | 双面抛光、工作边圆钝 | 弯曲疲劳、毛刺和成型一致性 |
| 挂钩 | 316L 或 PEEK | 精抛圆角、永久批次标识 | 折叠损伤、导轨磨损和回收寿命 |
| 链条导轨 | UHMW-PE | 低摩擦、机械固定、可更换 | 满筒压力下蠕变和磨损 |
| 夹具夹垫 | 聚氨酯或软铝分段垫 | 可更换、无硅污染 | 摩擦系数、压实和回弹 |

材料选择优先顺序为纤维不损伤、尺寸稳定、耐磨、可维护，最后才是最低采购成本。

## 4. 纱线接触面要求

### 4.1 圆角和孔口

所有纱线转向处满足：

```text
R_contact >= R_min_material
```

`R_min_material` 必须用目标纤维和实际张力试验确定。PDF 明确指出粘合针插入位置过近导向块会增加玻纤弯曲并导致断裂。[PDF p6.t17-p6.t20] [PDF 图3.28: p7; p7.t21]

陶瓷眼和金属孔口不得仅以图纸“去毛刺”验收，应使用放大检查和拖纱试验。建议把孔口圆角、崩边和表面划痕列为控制计划项目。

### 4.2 粗糙度

以下数值为工程建议：

| 接触类型 | 建议表面状态 |
|---|---|
| 陶瓷眼孔和孔口圆角 | 无可见崩边；供应商镜面级表面 |
| 拉剑钩、挂钩和接合槽 | `Ra <= 0.4 μm` |
| 筘片工作边 | `Ra <= 0.4 μm`，边缘连续圆钝 |
| 聚合物导向块滑动面 | `Ra <= 1.6 μm`，无注塑飞边 |
| 非纱线接触精密安装面 | `Ra <= 3.2 μm` |

最终粗糙度以拖纱损伤结果为准，而不是以单个表面数值替代功能试验。

## 5. 工程建议公差

| 项目 | 首台样机目标 | 状态 | 测量方法 |
|---|---:|---|---|
| 上下导向框架节距累计误差 | `<= 0.10 mm/300 mm` | 工程建议 | CMM 或光学测量 |
| 导向块单侧滑动间隙 | `0.08...0.15 mm` | 工程建议 | 塞规和温湿度记录 |
| 导向块厚度方向总间隙 | `0.10...0.20 mm` | 工程建议 | 塞规/位移表 |
| 三根拉剑相对高度误差 | `<= 0.10 mm` | 工程建议 | 三层检具和位移表 |
| 筘片对目标间隙中心偏差 | `<= 0.10 mm` | 工程建议 | 光学靶标/检具 |
| 左右牵引位置差 | `<= 0.10 mm` | 工程建议 | 双位置尺全行程记录 |
| 两根牵引丝杠平行度 | `<= 0.05 mm/500 mm` | 工程建议 | 激光或位移表 |
| 门架立柱相对 B/C 平行度 | `<= 0.10 mm/500 mm` | 工程建议 | 激光跟踪或方尺 |
| 针对可用间隙的单侧余量 | 初始 `>= 0.5 mm` | 工程建议 | 插入检具和包络分析 |
| 拉剑与相邻纱层单侧动态余量 `C_rapier,min` | 全工况保持正值；验收下限由纱线波动试验冻结 | 待冻结 | 高速视频、位移测量和包络分析 |
| 刚性活动件动态净间隙 | 初始 `>= 5 mm` | 工程建议 | 扫掠模型和高速视频 |
| 筘系统峰值弹性位移 | `<= 0.10 mm` | 工程建议 | 力加载和位移传感器 |

公差分配必须遵守 [08-parts-assembly-and-cad-breakdown.md](08-parts-assembly-and-cad-breakdown.md) 的公差所有权。调整件修正整体位置，不能掩盖节距、平面度或零件形状错误。

## 6. 清洁、润滑和紧固

| 区域 | 要求 |
|---|---|
| 纱线区 | 干式清洁；不得有外露润滑脂和切削液残留 |
| 直线导轨和丝杠 | 使用制造商允许润滑剂，并设置刮片和封闭护罩 |
| 链条 | 选择低飞溅润滑方式，链区与纱区实体隔离 |
| 聚合物滑轨 | 优先干摩擦；如需润滑必须验证纤维和上浆剂相容性 |
| 紧固件 | 按扭矩表装配；振动区使用机械防松或经批准的螺纹锁固剂 |
| 定位销和基准面 | 薄层防锈，装配前擦净，不用厚油膜填补误差 |

维护计划需按周期记录粉尘、纤维毛羽、磨屑和异常温升。任何可能迁移到预制体的化学品都需材料相容性批准。

## 7. 制造流程

### 7.1 主机架

1. 下料和焊接 A11/A13/A14，保留加工余量。
2. 焊后消除应力并检查整体扭曲。
3. 同次装夹加工两条 A 基准梁、定位孔和关键门架接口。
4. 试装导轨和子总成后再完成涂装。
5. 涂装时遮蔽基准面、接地点和定位孔。

### 7.2 导向框架

1. G-01/G-02 成对加工定位孔、隔套座和耐磨条槽。
2. 用主检具加工或检测节距特征，避免两板独立累积误差。
3. 耐磨条单独编号，可更换并保留选择配合记录。
4. 导向块按批次测量宽度和厚度，禁止未经评估混装极限尺寸批次。
5. 装入陶瓷眼后检查崩边、同轴和压装应力。

### 7.3 细长和薄片零件

- 针在热处理和抛光后进行直线度与表面检查。
- 拉剑根部连接在总成状态测挠度和固有频率。
- 筘片使用专用夹具成组定位，工作边最终抛光后不得二次冲裁。
- 挂钩用成形检具检查纱线鼻和捕获脚，按批次进行拖纱测试。

## 8. 验证样件和检具

正式整机前先制造以下低成本样件：

| 样件 | 目的 | 关键输出 |
|---|---|---|
| 单纱转向试验件 | 确定 `R_min_material` 和表面要求 | 断丝率、毛羽、张力损失 |
| 5 至 10 块导向轨样件 | 确定材料、间隙和污染敏感性 | 推力、磨损、卡滞阈值 |
| 单端转层梭样件 | 验证端块捕获和入位 | 允许错位、冲击和寿命 |
| 单针和交叉纱检具 | 验证针径、自由长和插入点 | 插入力、弯曲半径、屈曲裕量 |
| 单拉剑钩纱台 | 验证钩口和释放斜面 | 拾取/释放成功率和峰值力 |
| 三槽交接台 | 验证拉剑与接合杆配合 | 丢圈率、夹纱和层高容差 |
| 单段开放筘试验台 | 测峰值力和纱线损伤 | 打纬力、筘片挠度和磨损 |
| 夹具压实样件 | 确定夹垫材料和压力 | 摩擦系数、压扁、层间滑移 |
| 挂钩和导轨循环台 | 验证插入、滑动和回收 | 缺钩、卡滞、磨损和寿命 |

## 9. 计算和仿真门槛

加工图前至少完成：

1. 满筒和空筒偏斜供纱链惯量及 M1 峰值扭矩。
2. 洁净、粉尘和最大张力状态的导向索引力。
3. 上下反向机构的机架反力平衡。
4. 拉剑最大挠度、根部应力和一阶固有频率。
5. 粘合针屈曲、弯曲和疲劳裕量。
6. 筘水平轴峰值力、丝杠寿命和门架挠度。
7. 牵引夹具梁挠度、夹持压力和双丝杠同步轴扭转。
8. 丝杠临界转速、轴承寿命和热伸长。
9. 整机周期激励与机架固有频率分离。
10. 急停制动距离和当前状态下的无碰撞退出路径。

计算输入、模型版本、边界条件和安全系数必须随评审记录保存。计算公式和载荷路径见 [06-transmission-interfaces-and-dynamics.md](06-transmission-interfaces-and-dynamics.md)。

## 10. 分阶段验证

### 10.1 L0 零件级

1. 材料证书和热处理状态正确。
2. 关键尺寸和基准满足图纸。
3. 陶瓷眼无崩边，金属接触边无毛刺。
4. 导向块、针、筘片和挂钩有可追溯批次标识。

### 10.2 L1 运动副级

1. 全行程只有规定自由度，无局部紧点。
2. 洁净和规定粉尘状态下记录启动力、运行力和回差。
3. 硬限位先于结构碰撞生效。
4. 可更换件拆装后重复定位满足接口要求。

### 10.3 L2 子总成级

| 子总成 | 最低验证 |
|---|---|
| A30/A31 | 满筒、空筒、失张力和制动状态的一工位索引 |
| A40/A41 | S0/S1/S2 占用正确，连续 1000 次换位无卡滞和累计错位 |
| A42 | 空载和额定负载下输出相位一致；离合器设定、回差和一工位重复性满足冻结值 |
| A50 | 针全行程、屈曲保护、恒力回收器空载行程和安全退出 |
| A60 | 三钩头全行程对中、硬限位和最大挠度 |
| A61 | 三槽全行程、层高对中、硬限位和交接路径 |
| A70 | 矩形路径、力限幅、峰值挠度和异常退出 |
| A80 | 左右同步插钩、缺钩检测和导轨滑动 |
| A90 | 全行程左右差、夹紧防滑、抱闸和手动释放 |

### 10.4 L3/L4 配对和织造区

1. 上下框架和上下供纱链全循环编号一一对应。
2. 拉剑、接合杆和筘完成两次填充路径，无刚性件碰撞。
3. 粘合针只在允许间隙进入，拉剑和筘互锁有效。
4. 所有名义动态间隙在实测挠度和伺服误差下仍为正。
5. 模拟每一种传感器不到位和扭矩/力超限，机构保持安全状态。

### 10.5 L5 整机无纱

1. 按 [07-timing-interlocks-and-control.md](07-timing-interlocks-and-control.md) 连续执行 1000 个完整周期。
2. 导向块、供纱链、挂钩和牵引计数无累计错相。
3. 拉剑、针、筘和接合杆按最小设计间隙无碰撞。
4. M1 扭矩离合器在模拟卡块时可靠脱开且不自动反复冲击。
5. 急停在每个离散状态测试，恢复不执行无条件全轴回零。

### 10.6 软线试织

使用高可见度软线分别表示 `0°`、`+θ`、`-θ`、`90°` 和 `Z` 向纱：

1. 每次偏斜索引后形成可供针和筘进入的间隙。
2. 三根拉剑每次形成三个完整纱圈。
3. 接合杆不丢圈、不夹断，筘把纱圈送到 D 基准。
4. 边缘纱绕新挂钩折叠，不绕末端固定经纱折叠。
5. 实测偏斜角与 `tan(θ)=p/s` 比较。
6. 两次填充完成前牵引互锁不能释放。

### 10.7 目标纤维试织

1. 从最低张力和最低速度开始逐级增加，不直接满负荷运行。
2. 在陶瓷眼、针、钩头、接合槽、筘片和挂钩处检查断丝和毛羽。
3. 测量粘合纱实际最小弯曲半径。
4. 测量织物宽度、厚度、单位长度填充数和四层偏斜角。
5. 检查上下偏斜层关于中面的对称性。
6. 检查夹具是否造成局部压扁或层间错移。
7. 记录每根纱线张力波形、打纬峰值力、牵引力和周期时间。

## 11. 验收指标表

| 指标 | 初始门槛 | 冻结方式 |
|---|---:|---|
| 导向框架连续换位 | 1000 次无卡滞、掉块、累计错位 | 无纱和规定粉尘各一次 |
| 完整整机循环 | 1000 周期无碰撞、无错相 | L5 记录 |
| 三层拉剑拾取/释放 | 验证批次不丢圈 | 软线和目标纤维分别统计 |
| 牵引左右位置差 | 全行程 `<= 0.10 mm` | 双位置尺记录 |
| 筘总弹性位移 | 峰值 `<= 0.10 mm` | 额定打纬力加载 |
| 动态刚性件净间隙 | 初始 `>= 5 mm` | CAD 包络加实测误差复核 |
| 偏斜角 | 与 `atan(p/s)` 的容差由产品要求冻结 | 多位置图像测量 |
| 成型宽度 | `W` 的容差由产品要求冻结 | 连续样品多点测量 |
| 纤维损伤 | 不允许肉眼可见切伤；定量门槛待材料试验冻结 | 放大检查和质量对比 |
| 夹具层间滑移 | 产品允许值待试验冻结 | 标记点位移和厚度测量 |

1000 次/周期是样机调试门槛，不是生产寿命证明。量产寿命需要按目标周期数另行制定耐久和维护试验。

## 12. 测量与记录

每项验证记录至少包含：

1. 零件、总成和软件/运动配置版本。
2. 环境温度、湿度、纤维批次和上浆状态。
3. 张力、速度、加速度和润滑/粉尘条件。
4. 测量设备、校准状态和采样率。
5. 原始数据、照片、高速视频和异常状态。
6. 通过/失败判定及责任人。
7. 失败后的根因、修改和重复验证范围。

不得只保留“通过”结论而丢失实测值。任何工程建议值转为已验证值时，需在参数登记表中链接验证记录。

## 15. 变更控制

以下任一变更需要重新执行受影响的包络、动力学和试织验证：

1. `W`、`p`、`s`、`H_fill` 或层序变化。
2. `X_G`、`X_N`、`X_R` 或 D 基准变化。
3. 目标纤维、上浆剂或张力窗口变化。
4. 导向块、针、钩头、筘片、挂钩或夹垫材料变化。
5. M1 至 M10 的传动比、运动曲线或峰值速度变化。
6. 任一硬限位、零位、互锁或故障退出路径变化。

变更评审必须指出哪些既有证据仍有效、哪些验证需要重做，不能默认旧样机结果自动覆盖新配置。
